Programación IV

  • Periodo: 04 de septiembre al 01 de octubre
  • Modalidad: Taller intensivo (4 días por semana, 4 horas diarias)
  • Distribución: 3 horas de docencia + 1 hora de PAE/trabajo grupal.

Metodología

El interciclo se desarrollará mediante una metodología activa, práctica y centrada en el estudiante, priorizando el aprendizaje basado en proyectos y la resolución de problemas propios del desarrollo web. Se emplearán estrategias metodológicas como el Aprendizaje Basado en Problemas (ABP), el Aprendizaje Basado en Proyectos (ABPro), talleres prácticos, trabajo colaborativo y estudio de casos reales para fortalecer las competencias técnicas y profesionales.

Cronograma general

Semana Fechas Unidad del sílabo Competencia Laboratorio
1 04–11 septiembre Unidad I. HTML5 Talleres prácticos de programación y desarrollo web. Creación de la estructura semántica de páginas web, formularios, tablas, multimedia y accesibilidad.
2 14–18 septiembre Unidad II. CSS Desarrolla la estructura semántica de sitios web utilizando HTML5, aplicando estándares internacionales, etiquetas semánticas, formularios, elementos multimedia y buenas prácticas de accesibilidad para construir páginas web funcionales y organizadas. Diseño responsivo, Flexbox, Grid, animaciones, transiciones y estilos avanzados para interfaces web.

Gestor de Contenidos Implementa y administra sitios web utilizando gestores de contenidos (CMS), configurando temas, complementos, usuarios y contenidos para desarrollar soluciones web dinámicas, seguras y de fácil administración Instalación, configuración y personalización de WordPress; creación de sitios web, gestión de usuarios, plugins y temas.

Java Script Desarrolla aplicaciones web dinámicas mediante JavaScript, implementando estructuras de programación, manipulación del DOM, eventos, validación de formularios, consumo de APIs y programación orientada a objetos para mejorar la funcionalidad e interactividad de los sitios web. Programación del lado del cliente, manipulación del DOM, eventos, funciones, validación de formularios, consumo de APIs y desarrollo de aplicaciones web dinámicas.

Estructura de cada jornada

Hora Actividad HTML5
Hora 1 Exposición dialogada sobre la estructura de HTML5, etiquetas semánticas, formularios y activación de conocimientos previos mediante ejemplos reales.
Hora 2 Resolución guiada de ejercicios: creación de páginas web, tablas, listas, enlaces, imágenes, formularios y elementos multimedia utilizando HTML5.
Hora 3 Taller colaborativo para desarrollar la estructura de un sitio web aplicando estándares HTML5, análisis de problemas y socialización de resultados.
Hora 4 (PAE) Desarrollo del portafolio digital, práctica experimental grupal, uso de ChatGPT como apoyo para optimizar código HTML, mapas conceptuales, cuadros comparativos y retroalimentación del proyecto web.
Hora Actividad CSS
Hora 1 Exposición dialogada sobre CSS3, selectores, modelo de cajas, Flexbox, Grid y diseño responsivo mediante ejemplos prácticos.
Hora 2 Resolución guiada de ejercicios aplicando estilos, colores, tipografías, animaciones, transiciones y diseño adaptable.
Hora 3 Taller colaborativo para diseñar interfaces responsivas, resolución de problemas de diseño y socialización de propuestas.
Hora 4 (PAE) Portafolio digital, práctica experimental grupal de maquetación web, uso de ChatGPT para optimización de estilos CSS, mapas mentales, cuadros comparativos y seguimiento del proyecto integrador.
Hora Actividad Gestor de Contenidos (CMS)
Hora 1 Exposición dialogada sobre gestores de contenidos, instalación de WordPress, temas, plugins y administración del sitio web.
Hora 2 Resolución guiada de ejercicios para instalar, configurar y administrar un CMS, usuarios, páginas y contenidos.
Hora 3 Taller colaborativo para desarrollar un sitio web utilizando WordPress, resolución de problemas y presentación de resultados.
Hora 4 (PAE) Portafolio digital, práctica experimental grupal, personalización del sitio web, uso de ChatGPT para apoyo en configuración y generación de contenidos, cuadros comparativos y seguimiento del proyecto.
Hora Actividad JavaScript
Hora 1 Exposición dialogada sobre variables, funciones, eventos, DOM, estructuras de control y programación orientada a objetos en JavaScript.
Hora 2 Resolución guiada de ejercicios para desarrollar scripts, validar formularios, manipular el DOM y consumir APIs.
Hora 3 Taller colaborativo para desarrollar funcionalidades dinámicas del proyecto web, resolución de problemas y socialización del código implementado.
Hora 4 (PAE) Portafolio digital, práctica experimental grupal, uso de ChatGPT para depuración y optimización del código JavaScript, mapas mentales, cuadros comparativos, competencias gamificadas (Kahoot, Quizizz, Blooket y Gimkit) y evaluación continua del proyecto integrador.

Planificación semanal

Semana Resultados de aprendizaje Temas Actividades y evidencias
Semana 1 Desarrolla la estructura de páginas web utilizando HTML5, aplicando etiquetas semánticas, formularios, tablas, listas y elementos multimedia conforme a los estándares de desarrollo web y accesibilidad.

Unidad I. HTML5

  • Introducción a HTML5.
  • Estructura básica de un documento HTML.
  • Etiquetas semánticas.
  • Texto, listas, tablas e imágenes.
  • Hipervínculos.
  • Formularios.
  • Audio y video.
  • Buenas prácticas de codificación.
  • Talleres de creación de páginas web.
  • Elaboración de un mapa mental sobre etiquetas HTML5.
  • Desarrollo de formularios y tablas.
  • Uso de ChatGPT para explicar y optimizar código HTML.
  • Competencia Kahoot.
  • Competencia Quizizz.
  • Práctica experimental grupal.
  • Portafolio digital.
Semana 2 Diseña interfaces web responsivas utilizando CSS3, aplicando estilos, selectores, Flexbox, Grid, animaciones y principios de experiencia de usuario para mejorar la presentación de los sitios web.

Unidad II. CSS3

  • Introducción a CSS.
  • Selectores y propiedades.
  • Modelo de cajas.
  • Flexbox.
  • CSS Grid.
  • Tipografía y colores.
  • Diseño responsivo.
  • Animaciones y transiciones.
  • Talleres de maquetación web.
  • Cuadro comparativo entre Flexbox y CSS Grid.
  • Diseño responsivo de una página web.
  • Uso de ChatGPT para optimización de estilos CSS.
  • Competencia Kahoot.
  • Competencia Blooket.
  • Práctica experimental grupal.
  • Portafolio digital.
Semana 3 Implementa y administra un Gestor de Contenidos (CMS) para desarrollar sitios web dinámicos, configurando temas, plugins, usuarios y contenidos de manera eficiente y segura.

Unidad III. Gestor de Contenidos (CMS)

  • Introducción a los CMS.
  • Instalación de WordPress.
  • Configuración inicial.
  • Temas y plugins.
  • Gestión de usuarios.
  • Creación de páginas y entradas.
  • Seguridad y respaldo.
  • Instalación y configuración de WordPress.
  • Desarrollo colaborativo de un sitio web.
  • Portafolio parcial.
  • Uso de ChatGPT para resolver problemas de configuración.
  • Competencia Quizizz.
  • Competencia Gimkit.
  • Práctica experimental grupal.
Semana 4 Desarrolla aplicaciones web dinámicas utilizando JavaScript, implementando eventos, manipulación del DOM, validación de formularios y funciones para mejorar la interacción y funcionalidad de los sitios web.

Unidad IV. JavaScript

  • Introducción a JavaScript.
  • Variables y tipos de datos.
  • Operadores y estructuras de control.
  • Funciones.
  • Eventos.
  • Manipulación del DOM.
  • Validación de formularios.
  • Introducción al consumo de APIs.
  • Desarrollo de ejercicios integradores.
  • Implementación de funcionalidades dinámicas en el proyecto web.
  • Portafolio final.
  • Socialización del proyecto integrador.
  • Uso de ChatGPT como asistente para depuración y optimización del código.
  • Kahoot Final.
  • Presentación de la práctica experimental grupal.
  • Evaluación integradora.
