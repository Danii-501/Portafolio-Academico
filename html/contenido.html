Actividad N.° 1: Variables y variables variables en PHP

Unidad Unidad I. HTML5
Modalidad Individual
Tema Variables y variables variables en PHP
Objetivo Comprender el uso de variables básicas y variables variables ($) en PHP, reforzando la sintaxis de echo/print, la interpolación de variables en cadenas de texto y la identificación de errores comunes de sintaxis.

Desarrollo

En un primer ejercicio se declararon las variables $valor y $VALOR, mostrando que PHP distingue mayúsculas de minúsculas. En un segundo ejercicio se trabajó con variables variables: a partir de $a = "php", la instrucción $a creó dinámicamente una variable llamada $php, a la que se le asignó el texto "programacion"; luego se mostró su valor usando dos sintaxis distintas: $a y ${$a}. En un tercer ejercicio se intentó seleccionar un mensaje según el idioma, concatenando el texto "mensaje_" con el valor de $idioma para formar el nombre de una variable; sin embargo, al usar print sin la sintaxis de variable variable, se mostró el nombre de la variable como texto en lugar de su valor real.

Código

Ejercicio 1: variables básicas

<?php
$valor = 5;
$VALOR = "hola";
echo $VALOR;
echo "<br>";
echo $valor;
?>

Ejercicio 2: variables variables

<?php
$a = "php";
$a = "programacion";
echo "$a $php" . "<br>";
echo "$a " . ${$a};
?>

Ejercicio 3: selección de mensaje según idioma

<?php
$mensaje_es = "hola";   // español
$mensaje_en = "hello";  // ingles
$idioma = "en";
$mensaje = "mensaje_" . $idioma;
print ${$mensaje};
?>

Resultado

[Espacio para captura: Código 1, Código 2 y Código 3]

Aprendizajes y dificultades

  • Se comprendió que $variable y ${$variable} son dos formas equivalentes de crear o leer una variable variable en PHP.
  • Se identificó un error en el código original del ejercicio 3: se declaró dos veces $mensaje_es en lugar de crear $mensaje_en, lo que hacía que la variable en inglés no existiera.
  • Se detectó que print $mensaje; solo imprime el texto "mensaje_en" (el nombre de la variable), y que para mostrar su valor real ("hello") es necesario usar ${$mensaje}.
  • Se corrigió también echo "<br></br>" por echo "<br>", ya que la etiqueta <br> no lleva cierre.

Conclusión

Esta práctica permitió reforzar el manejo de variables en PHP y comprender el funcionamiento de las variables variables, además de evidenciar la importancia de revisar la sintaxis para evitar errores que afecten el resultado esperado.

Actividad N.° 4: Comparación de números con la estructura condicional if / elseif / else

Unidad Unidad I. HTML5
Modalidad Individual
Tema Estructura condicional if / elseif / else en PHP
Objetivo Aplicar la estructura condicional if / elseif / else en PHP para comparar dos valores numéricos ingresados por el usuario.

Desarrollo

Se creó un formulario HTML con dos campos de texto para ingresar dos números. En PHP se utilizó isset() y se recibieron los valores mediante $_POST. Con una estructura condicional se comparó el primer número con el segundo.

Código

<form action="" method="post">
    <label>UTILIZACIÓN CONDICIÓN IF</label><br>
    <label>Ingrese primer numero</label>
    <input type="text" name="num1"><br>
    <label>Ingrese segundo numero</label>
    <input type="text" name="num2"><br>
    <input type="submit" name="submit1" value="ENVIAR">
</form>

<?php
if (isset($_POST["submit1"])) {
    $num1 = $_POST["num1"];
    $num2 = $_POST["num2"];

    if ($num1 == $num2) {
        echo "LOS DOS NUMEROS QUE INGRESARON SON IGUALES";
    } elseif ($num1 > $num2) {
        echo "EL PRIMER NUMERO ES MAYOR QUE EL SEGUNDO";
    } else {
        echo "EL SEGUNDO NUMERO ES MAYOR QUE EL PRIMERO";
    }
}
?>

Actividad N.° 5: Validación de cédula ecuatoriana con bucles for

Unidad Unidad I. HTML5
Modalidad Individual/Grupal
Tema Bucles for y la función substr() en PHP
Objetivo Aplicar bucles for y la función substr() en PHP para implementar el algoritmo de validación de la cédula ecuatoriana (módulo 10).

Desarrollo

Se creó un formulario HTML con un campo de texto para ingresar un número de cédula de 10 dígitos. En PHP, al recibir el valor, se aplicó el algoritmo oficial (módulo 10) utilizando bucles for y la función substr().

Código

<form method="POST">
    Cédula: <input type="text" name="num1" maxlength="10"><br><br>
    <input type="submit" value="Verificar">
</form>

<?php
if (isset($_POST["num1"])) {
    $n1 = $_POST["num1"];
    $sp = 0;
    $si = 0;

    // Sumar posiciones impares (1, 3, 5, 7)
    for ($i = 1; $i <= 7; $i = $i + 2) {
        $rest = substr($n1, $i, 1);
        $sp = $sp + $rest;
    }

    // Multiplicar posiciones pares por 2 (0, 2, 4, 6, 8)
    for ($i = 0; $i <= 8; $i = $i + 2) {
        $rest = substr($n1, $i, 1);
        $x = 2 * $rest;

        if ($x >= 10) {
            $x = $x - 9;
        }
        $si = $si + $x;
    }

    // Suma total
    $r = $sp + $si;
    $r1 = $r % 10;

    // Calcular dígito verificador
    if ($r1 == 0) {
        $nv = 0;
    } else {
        $nv = 10 - $r1;
    }

    // Obtener último dígito
    $ultimo = substr($n1, 9, 1);

    // Comparar
    if ($nv == $ultimo) {
        echo "Cédula correcta";
    } else {
        echo "Cédula incorrecta";
    }
}
?>

Resultado

[Espacio para captura de Resultados]

Aprendizajes y dificultades

  • Se comprendió el uso de substr($cadena, $posicion, $longitud) para extraer un solo dígito de un número tratado como texto.
  • Se reforzó el uso de bucles for con incrementos distintos de 1 ($i = $i + 2) para recorrer solo las posiciones impares o pares del número.
  • Se comprendió por qué se resta 9 cuando el doble de un dígito da 10 o más.
  • Se identificó la importancia de validar previamente que el número ingresado tenga exactamente 10 dígitos.

Conclusión

Esta práctica permitió comprender la lógica del algoritmo de validación de la cédula ecuatoriana, reforzando el manejo de bucles for y funciones de cadenas de texto en PHP.

Actividad N.° 1: Introducción a CSS con estilos en línea

Unidad Unidad II. CSS
Modalidad Individual
Tema Introducción a CSS: estilos en línea (inline)
Objetivo Comprender la forma más básica de aplicar CSS a una página HTML mediante el atributo style, modificando el color de texto de distintos elementos como primer acercamiento a las hojas de estilo.

Desarrollo

Se creó un documento HTML5 básico y se aplicaron estilos CSS directamente sobre los elementos mediante el atributo style, conocido como estilo en línea (inline). Al encabezado <h1> se le asignó la propiedad color: blue, y al párrafo <p> la propiedad color: red, comprobando que cada elemento puede tener su propio estilo de forma independiente sin necesidad de una hoja de estilos externa ni de una etiqueta <style>.

Código

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mis primeros Estilos CSS</title>
</head>
<body>
    <h1 style="color: blue;">Style color</h1>
    <p style="color: red;">Lorem ipsum, dolor sit amet consectetur adipisicing elit, vero ise</p>
</body>
</html>

Resultado

[Espacio para captura: Resultado visual del HTML en el navegador]

Aprendizajes y dificultades

  • Se comprendió que CSS puede aplicarse directamente sobre un elemento HTML mediante el atributo style, sin necesidad de un archivo aparte.
  • Se identificó la sintaxis básica de una propiedad CSS: propiedad: valor;, en este caso color: blue; y color: red;.
  • Se reconoció que el estilo en línea afecta únicamente al elemento donde se escribe, y que para estilos repetidos en varios elementos existen formas más eficientes, como CSS interno o externo.

Conclusión

Esta práctica permitió dar el primer acercamiento a CSS, comprendiendo cómo modificar la apariencia de los elementos HTML mediante estilos en línea como base para técnicas más avanzadas de diseño web.

Actividad N.° 2: Estructura semántica para practicar selectores CSS

Unidad Unidad II. CSS3
Modalidad Individual
Tema Selectores CSS aplicados sobre una estructura HTML5 semántica
Objetivo Construir una estructura HTML5 semántica (encabezado, contenido principal y artículos) enlazada a una hoja de estilos externa, como base para aplicar selectores CSS de etiqueta, clase e ID.

Desarrollo

Se construyó la estructura de un blog utilizando etiquetas semánticas de HTML5: <header> para el encabezado con el título, una breve presentación y los enlaces de navegación; y <main> como contenedor del contenido principal, dentro del cual se repitieron tres bloques <article>, cada uno con un título (<h2>) y un párrafo con un enlace interno. La página se vinculó a una hoja de estilos externa (estilos.css) mediante la etiqueta <link>, de modo que los estilos se definen por separado del contenido, permitiendo aplicar selectores CSS (de etiqueta, de clase o de ID) para dar formato a cada parte de la estructura de forma organizada.

Código HTML

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Selectores</title>
    <link rel="stylesheet" href="estilos.css" />
</head>
<body>
    <header>
        <h1>Mi blog</h1>
        <p>Yo soy Carlos Arturo y este es mi blog</p>
        <a href="">Inicio</a>
        <a href="">Blog</a>
        <a href="">Contacto</a>
    </header>

    <main>
        <article>
            <h2>Título #1</h2>
            <p>
                Lorem ipsum <a href="">dolor sit amet</a> consectetur adipisicing elit. Sed consequatur aliquid odit quibusdam reprehenderit omnis totam, maiores ratione enim veniam?
            </p>
        </article>

        <article>
            <h2>Título #2</h2>
            <p>
                Lorem ipsum dolor<a href="">dolor sit amet</a> sit amet consectetur adipisicing elit. Sed consequatur aliquid odit quibusdam.
            </p>
        </article>

        <article>
            <h2>Título #3</h2>
            <p>
                Lorem ipsum dolor <a href="">dolor sit amet</a>sit amet consectetur adipisicing elit. Sed consequatur aliquid odit quibusdam.
            </p>
        </article>
    </main>
</body>
</html>

Resultado

[Espacio para captura de Resultados Visuales]

Aprendizajes y dificultades

  • Se reforzó el uso de etiquetas semánticas de HTML5 (<header>, <main>, <article>) frente al uso de <div> genéricos, mejorando la estructura y la accesibilidad de la página.
  • Se comprendió la ventaja de vincular una hoja de estilos externa con <link rel="stylesheet"> en lugar de estilos en línea, separando el contenido de la presentación.
  • Se identificó que repetir la misma estructura (<article>) varias veces facilita aplicar selectores de etiqueta que afecten a todos los elementos iguales de forma simultánea.

// Validación de Formulario
const formulario = document.querySelector('#miFormulario');

formulario.addEventListener('submit', (e) => {
    e.preventDefault();
    const email = document.querySelector('#emailInput').value;
    
    if (email.trim() === '' || !email.includes('@')) {

});

// Consumo de API remota con async/await
async function obtenerDatosAPI() {
    try {
        const respuesta = await fetch('https://jsonplaceholder.typicode.com/users/1');
        const data = await respuesta.json();
        document.querySelector('#datosUsuario').innerHTML = `
            <p><strong>Nombre:</strong> ${data.name}</p>
            <p><strong>Email:</strong> ${data.email}</p>
        `;
    } catch (error) {
        console.error('Error al consumir la API:', error);
    }
}

// ANTES: Código antiguo con callbacks tradicionales
function obtenerUsuario(id, callback) {

        setTimeout(() => {
            resolve({ id, nombre: "Estudiante" });
        }, 1000);
    });
};

// Uso limpio con async/await
const ejecutar = async () => {
    const usuario = await obtenerUsuarioOptimizado(1);
